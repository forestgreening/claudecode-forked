# PinShot 서비스 기획서

## 1. 서비스 개요

### 비전
자주 바뀌는 임시 정보를 사진 한 장으로 간편하게 기억하는 앱

### 해결하는 문제
헬스장 락커 번호, 주차 위치 등 매번 바뀌는 임시 정보를 사진으로 찍어두면 갤러리에 쌓이고, 나중에 지워야 하는 번거로움이 있다. 또한 운동 후 락커 번호나 비밀번호가 기억나지 않는 상황이 빈번하게 발생한다.

### 핵심 가치 제안 (Value Proposition)
"슬롯" 개념으로 카테고리별 마지막 사진만 자동 유지 — 찍으면 이전 사진은 자동 교체되어 갤러리가 더럽혀지지 않고, 필요한 정보만 항상 최신 상태로 유지된다.

## 2. 타겟 사용자 페르소나

### 페르소나 1: 직장인 헬스러 민수 (29세)
- **프로필**: 퇴근 후 헬스장에 다니는 직장인
- **니즈**: 매일 바뀌는 락커 번호와 비밀번호를 빠르게 기록
- **페인포인트**: 운동 후 땀 흘리고 나오면 락커 번호가 기억이 안 남. 사진을 찍어놓으면 갤러리에 쌓여서 나중에 정리해야 함
- **기대하는 것**: 한 번 찍으면 알아서 관리되는 간편함

### 페르소나 2: 운전자 지현 (35세)
- **프로필**: 매일 다른 곳에 주차하는 외근직
- **니즈**: 주차 위치를 빠르게 기록하고 나중에 바로 확인
- **페인포인트**: 대형 주차장에서 주차 위치를 잊어버려 헤맨 경험 다수
- **기대하는 것**: 앱을 열지 않고도 위젯으로 바로 확인

### 페르소나 3: 다양한 임시 정보 관리가 필요한 사람
- **프로필**: 임시 비밀번호, 택배 보관함 번호, 좌석 번호 등을 자주 기억해야 하는 사람
- **니즈**: 카테고리별로 최신 정보만 깔끔하게 관리
- **페인포인트**: 메모 앱은 과하고, 사진 앱은 정리가 안 됨
- **기대하는 것**: 목적에 딱 맞는 단순한 도구

## 3. MVP 기능 정의

### 핵심 기능 (Must-Have)

| 우선순위 | 기능명 | 설명 | 사용자 가치 |
|----------|--------|------|-------------|
| P0 | 슬롯 관리 | 텍스트 이름으로 슬롯 추가/삭제/편집 | 카테고리별 정보 분류 |
| P0 | 사진 촬영 & 자동 교체 | 슬롯 선택 후 사진 촬영 시 이전 사진 자동 교체 | 핵심 기능 — 항상 최신 사진만 유지 |
| P0 | 사진 뷰어 | 슬롯별 마지막 사진 확인 | 필요할 때 바로 확인 |
| P1 | 홈 위젯 | 홈 화면에서 앱을 열지 않고 슬롯 사진 확인 | 빠른 접근성 |
| P1 | 온보딩 가이드 | 첫 설치 시 사용법 안내 (2~3 화면) | 앱의 독특한 컨셉 이해 도움 |
| P2 | 광고 통합 | 배너 또는 인터스티셜 광고 | 수익 창출 |

### 후순위 기능 (Nice-to-Have)
- 슬롯 아이콘/색상 커스터마이징
- 사진 히스토리 (최근 N장 보관 옵션)
- 갤러리에서 사진 가져오기 (촬영 대신)
- 슬롯 정렬/그룹핑
- 다크모드
